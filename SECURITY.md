# Security

zSol is a wallet: a security bug can cost people money. Thank you for reporting one privately.

## Reporting a vulnerability

Use GitHub's private reporting: open this repository's **Security** tab and press
**Report a vulnerability**. Please do not open a public issue or pull request for it.

Include what you found, how to reproduce it, and what an attacker could do with it. We answer
within 3 working days and keep you updated until it is fixed.

## Scope

- This extension's code and its build.
- How the extension talks to zsol.cc.

Bugs in zsol.cc itself are welcome through the same form.

## Official releases

The only official builds are the ones linked from [zsol.cc](https://zsol.cc). An extension that
uses the zSol name anywhere else is not ours.
